PR6 - Database operations (a to j)
Operations a to j + date and time (all parts in one file: 6a ALTER, 6b DROP, 6c INDEX, 6d OPERATORS, 6e LIKE, 6f GROUP BY, 6g NESTED, 6h SET OPS, 6i VIEWS, 6j SORTING, 6k DATE/TIME)
File: pr6_database_operations   |   94 steps
========================================================================

HOW TO USE: do the steps in order. Copy ONLY the code between the two
dashed lines of one step, paste it at the mysql> prompt, press Enter,
then go to the next step. Steps marked [ERROR DEMO] are supposed to give an error.

NOTES:
  * 6d: MySQL has no !< and !> operators (they are SQL Server only). Use >= and <= instead.
  * 6d: The manual's arithmetic example  WHERE SALARY = SALARY + 1000  is never true. Here the arithmetic is shown in the SELECT list instead.
  * 6e: % matches any number of characters, _ matches exactly one character.
  * 6h: MySQL does not have MINUS; the same operator is called EXCEPT.
  * 6h: INTERSECT and EXCEPT need MySQL 8.0.31+ or MariaDB 10.3+. On older versions use the two alternative steps at the end.
  * 6h: The manual uses hostel1 and hostel2 but never creates them; they are created here.
